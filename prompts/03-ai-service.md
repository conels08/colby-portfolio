# Prompt 03 — Add AI & Automation Service

In `src/data/projects.ts`, add a fourth entry to the `services` array.

Insert it as the **second item** in the array (after "Business Websites", before "Full-Stack MVPs"):

```ts
{
  title: "AI & Automation",
  description: "Custom AI agents and automations that eliminate repetitive work and plug directly into your tools and workflows.",
  features: [
    "AI-powered workflows",
    "Custom agent development",
    "API and tool integrations",
    "Process automation",
    "ChatGPT / Claude integration"
  ]
}
```

No other changes to the file.

> Note: The services grid will go from 3 to 4 columns — check how this looks on mobile after applying.
